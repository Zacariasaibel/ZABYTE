# Project instructions

- Work only inside this ECommerceShop workspace. Preserve other projects and the published portfolio.
- Use simple, natural German for the interface and public README.
- Use English for code, identifiers and code comments.
- Use Spanish for explanations and learning documentation.
- Do not stage, commit, push or publish.
- Frontend: standalone Angular, strict TypeScript and CSS in frontend/.
- Backend: Django and Django REST Framework with SQLite in backend/; Python environment in root .venv/.
- Install dependencies locally, never globally. Keep secrets and local data out of source control.
- Current scope: read-only public catalog, persistent browser cart, server-validated simulated orders and protected Django Admin. No customer accounts, payments, card data or real fulfillment.
- Keep existing product IDs, slugs, prices, stock, categories and studio-image assignments. Simulated orders never decrement stock.
- Use the blue palette specified by the user. Fictional-project and generated-image notices belong in documentation, not catalog UI.
